# AceleraTalent mods para Claude Code

| Mod | Qué hace |
|---|---|
| `code-tutor` | Explica el porqué de cada cambio de código en un panel propio y responde preguntas con `/tutor`. |
| `productivity-hud` | Contexto, costo, burn-rate y presupuesto de la sesión, sobre el prompt y en un panel. |

## Instalación

Dentro de Claude Code:

```
/plugin marketplace add AceleraTalent/Mods-Claude
/plugin install code-tutor@aceleratalent-mods
/plugin install productivity-hud@aceleratalent-mods
```

Luego reinicia Claude Code (o usa `/reload-plugins`).

Para actualizar: `/plugin marketplace update aceleratalent-mods`.
